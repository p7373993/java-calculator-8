# java-calculator-precourse

-----

## 기능 목록

### 기본 구분자 기능

- [x] **쉼표(,)** 또는 **콜론(:)** 를 구분자로 사용

### 커스텀 구분자 기능

- [x] "**//**"  와 "**\n**" 사이에 위치한 문자를 커스텀 구분자로 사용
    - [x] 커스텀 구분자로 여러 문자 사용

### 예외 처리 기능

- [ ] 잘못된 값을 입력할 경우 IllegalArgumentException을 발생
- 예외 조건
    - [x] 잘못된 숫자(음수, 소수, 0) 사용
        - 소수는 마침표(.) 때문에 어처피 사용 불가
    - [x] 문자열 내 공백 포함(예: "3:2 1:3","3 : 2")
    - [ ] 선언한 커스텀 구분자 외 사용(예: "//#\n3&2")
    - [ ] 문자열 끝에 구분자 사용(예: "3:2:")

### 계산 기능

- [x] 분리된 숫자 모두 더하기

### 출력 기능

- [x] 합산된 결과 출력

### 추가 기능

- [x] 빈문자열은 0 출력

-----

## 기능 플로우

1. 사용자로부터 문자열 입력
    1. 빈문자열 검사
2. 커스텀 구분자 검사
3. 사용할 구분자 저장
4. 구분자를 사용해 숫자 분리
    1. 예외 처리
5. 분리된 숫자 합산
6. 결과 출력
